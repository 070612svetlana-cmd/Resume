# AI-портфолио Светланы Семеновой

Готовый базовый проект портфолио-лендинга на чистом HTML/CSS/JS:

- приветственный экран;
- переключение светлой/темной темы;
- анимации появления секций;
- разделы под портфолио работ.

## Структура

- `index.html` - главная страница.
- `assets/styles.css` - стили и темы.
- `assets/main.js` - логика темы и анимаций.
- Папки под работы:
  - `GPT-агенты и AI-боты`
  - `Сайты Лендинги`
  - `Логотипы, паттерны, иконки, брендбуки и иллюстрации в едином стиле`
  - `Нейровидение, ролики`
  - `Нейроилюстрации, изображения`
  - `Разукрашки для детей`
  - `Ретушь и восстановление старых фотографий`

## Как запустить

1. Откройте `index.html` в браузере.
2. Для корректной локальной навигации достаточно обычного открытия файла.

## Как добавить работы позже (автоподхват)

1. Положите изображения, видео и документы в соответствующие папки.
2. Выполните команду в корне проекта:

   `node scripts/generate-portfolio-manifest.mjs`

3. Обновите страницу — карточки портфолио заполнятся автоматически из файла `assets/portfolio-manifest.js`.

> Генератор сам определяет тип файлов (изображения/видео/документы) и собирает данные по всем папкам портфолио.

## Рекомендации по файлам

- Изображения: `png`, `jpg`, `jpeg`, `webp`.
- Видео: `mp4`, `webm`.
- Документы: `pdf`.

Автоподхват уже подключен: `index.html` загружает `assets/portfolio-manifest.js`, а галерея строится на его основе.
